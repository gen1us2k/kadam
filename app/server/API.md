# HTTP API

Бэкенд (`server/main.ts`) отдаёт два прикладных эндпоинта — распознавание речи с оценкой
произношения и синтез речи — плюс health-check. Всё остальное на этом же порту — раздача
собранного сайта (`dist/`). Реализация: `node:http` + `onnxruntime-node`, без фреймворка.

- **Base URL:** тот же origin, что и сайт. По умолчанию `http://localhost:4321` (переопределяется
  `PORT`). В dev-режиме (`npm run dev`, :4322) Astro проксирует `/api/*` на сервер.
- **CORS:** заголовок `Access-Control-Allow-Origin` ставится только для `http://localhost:4321` и
  `http://localhost:4322`. В обычной работе всё same-origin, поэтому CORS не задействован.
- **Формат ошибок:** любой не-2xx отвечает JSON `{"error": "<текст>"}`. Неизвестный `/api/*` → `404`.
  Непойманное исключение → `500 {"error":"internal error"}`.

Аудио везде — **16 кГц, mono, 16-bit PCM WAV**.

---

## `GET /api/health`

Проверка живости (модели загружены при старте до `listen`).

**200 OK** → `{"ok": true}`

```bash
curl http://localhost:4321/api/health
# {"ok":true}
```

---

## `GET /api/tts`

Синтезирует кыргызскую речь (Meta MMS `mms-tts-kir`) и возвращает WAV.

**Query**

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `text` | string | да | Текст для озвучки. Обрезается по краям (`trim`). Максимум **300** символов. |

**Ответ**

- **200 OK** — тело: `audio/wav` (16 кГц mono 16-bit). Заголовки: `Content-Length`,
  `Cache-Control: public, max-age=31536000` (одна и та же строка кешируется браузером —
  синтез псевдослучаен по шуму, но одного рендера на слово достаточно).

**Ошибки**

| Код | Когда | Тело |
|---|---|---|
| `422` | `text` пустой/отсутствует | `{"error":"missing ?text="}` |
| `413` | `text` длиннее 300 символов | `{"error":"text longer than 300 chars"}` |
| `422` | все символы вне словаря модели (синтезировать нечего) | `{"error":"nothing to synthesize"}` |

```bash
curl "http://localhost:4321/api/tts?text=салам" -o salam.wav
# salam.wav — ~1 с речи, 16 кГц mono WAV
```

Символы вне словаря MMS молча пропускаются; регистр складывается к нижнему (`tokenize`).

---

## `POST /api/asr/analyze`

Распознаёт кыргызскую речь (wav2vec2-large-xlsr-kyrgyz) и оценивает произношение относительно
**известной целевой фразы** через CTC forced alignment (Viterbi) — надёжнее нечёткого сравнения
транскрипта.

**Query**

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `target` | string | да | Фраза, которую пытались произнести. Обрезается по краям. По ней считается пофонемный GOP. |

**Тело запроса**

Сырые байты WAV (`Content-Type: audio/wav`), **16 кГц mono 16-bit PCM**. Лимит — 30 секунд аудио
(≈ 960 044 байт с заголовком). Минимум — 0.1 с.

**Ответ 200 OK** → `application/json` (`Analysis`):

```jsonc
{
  "transcript": "сала",   // открытый greedy-CTC декод — что «услышала» модель
  "percent": 80,          // общая оценка произношения 0..100 (среднее по буквам)
  "letters": [            // по одной записи на букву целевой фразы
    { "ch": "с", "score": 0.99 },
    { "ch": "а", "score": 0.99 },
    { "ch": "л", "score": 0.99 },
    { "ch": "а", "score": 0.99 },
    { "ch": "м", "score": 0.00 },
    { "ch": " ", "score": 0, "gap": true }  // пробел — разрыв слов, в percent не входит
  ]
}
```

- `letters[].score` — акустическая уверенность буквы (0..1), округляется до 4 знаков.
- `letters[].gap: true` — позиция пробела между словами; не оценивается и исключается из `percent`.
- Буквы целевой фразы вне выходного словаря модели (напр. `<s>`/`</s>`) пропускаются; `ё` → `е`.

**Ошибки**

| Код | Когда | Тело |
|---|---|---|
| `422` | `target` пустой/отсутствует | `{"error":"missing ?target="}` |
| `413` | тело больше лимита (по `Content-Length` или по факту чтения) | `{"error":"body too large"}` |
| `422` | не WAV / нет `fmt`/`data` чанка | `{"error":"not a WAV file"}` / `{"error":"missing fmt/data chunk"}` |
| `422` | формат не 16 кГц mono 16-bit | `{"error":"expected 16 kHz mono 16-bit PCM WAV"}` |
| `413` | аудио длиннее 30 с | `{"error":"audio longer than 30s"}` |
| `422` | аудио короче 0.1 с | `{"error":"audio too short"}` |

```bash
curl -X POST "http://localhost:4321/api/asr/analyze?target=салам" \
     -H "Content-Type: audio/wav" \
     --data-binary @utterance.wav
# {"transcript":"сала","percent":80,"letters":[...]}
```

Клиент (`src/lib/asr.ts`) кодирует записанное аудио в WAV (`src/lib/audio.ts encodeWav`) и шлёт
сырым телом; та же `Analysis` раньше считалась в браузере — контракт сохранён при переносе на бэкенд.
