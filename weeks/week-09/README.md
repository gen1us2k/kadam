# Неделя 9 — Активация речи

С этой недели новой грамматики нет — фаза активации: превращаем пассивное знание в речь. Словарь — 1200 слов.

## Программа недели

**Ежедневно:**
1. **Пересказ дня вслух** (5 минут перед сном): 8–10 предложений о прошедшем дне на кыргызском. Никто не слушает — говорите стенам. Это самое дешёвое и самое эффективное упражнение фазы.
2. **Shadowing** (10 минут): включите аудио с чёткой речью (новости Азаттык), повторяйте за диктором с отставанием в 1–2 секунды, копируя интонацию. Понимать всё не обязательно.
3. Anki 20 мин, аудирование 20 мин — как раньше.

**3 раза в неделю — носитель.** Темы сессий:
- Сессия 1: расскажите про свою неделю (прошедшее время + -ып-цепочки).
- Сессия 2: планы и желания (будущее + -гым келет + керек).
- Сессия 3: свободный диалог, носитель задаёт вопросы.

## Фразы для выражения мнения — выучить в начале недели

| Кыргызча | Орусча |
|---|---|
| Менимче, ... | По-моему, ... |
| Мен макулмун. / Макул эмесмин. | Я согласен. / Не согласен. |
| Туура. / Туура эмес. | Верно. / Неверно. |
| Билбейм. | Не знаю. |
| Балким. | Возможно. |
| Албетте! | Конечно! |
| Мага ... жагат / жакпайт. | Мне нравится / не нравится ... |
| Кызык экен! | Интересно! |

## Правило недели

**Не переходить на русский при первом затыке.** Забыли слово — опишите его другими словами (*«тиги нерсе, аны менен жазабыз»* — «та штука, которой пишем»). Навык перифраза важнее словаря.
