# Неделя 7 — Связная речь: деепричастие -ып и союзы

**Цель недели:** перейти от отдельных предложений к связному рассказу. Словарь — 950 слов.

## 1. Деепричастие -ып — главный связыватель действий

**Основа + -ып/-ип/-уп/-үп** (после гласной — просто **-п**) соединяет последовательные действия. Кыргызская речь строится цепочками:

*Базарга бар**ып**, нан ал**ып**, үйгө келдим.* — Сходил на базар, купил хлеб и пришёл домой. (Время показывает только последний глагол.)

*Эртең менен тур**уп**, жуун**уп**, чай ич**ип**, жумушка бардым.* — Утром встал, умылся, попил чаю и пошёл на работу.

## 2. Составные глаголы с -ып — учить как единые слова

| Кыргызча | Орусча |
|---|---|
| сатып алуу | покупать («взяв продажей») |
| алып келүү | приносить |
| алып баруу | относить/отвозить |
| алып кетүү | забирать с собой |
| кирип чыгуу | заглянуть/зайти ненадолго |

## 3. Союзы и связки

| Кыргызча | Орусча |
|---|---|
| жана | и |
| же | или |
| бирок | но |
| анан | потом, затем |
| анткени / себеби | потому что |
| ошондуктан | поэтому |
| эгер ... -са | если ... |
| деген | который называется / под названием |

*Мен келбедим, **анткени** ооруп жаттым.* — Я не пришёл, потому что болел.
*«Эгер убактым бол**со**, барам.»* — Если будет время, пойду. (условная форма -са/-се)

## 4. Хочешь звучать естественно — жат/отур/тур/жүр

Вспомогательные глаголы уточняют характер действия; на старте достаточно узнавать их на слух: *окуп отурат* (сидит читает), *иштеп жүрөт* (работает [в этот период жизни]).

## Задания

1. Переписать 10 пар коротких предложений в одно с -ып: «Я встал. Я умылся» → *Туруп, жуундум.*
2. Рассказ «Мой обычный день» — 12–15 предложений цепочками с -ып, с союзами.
3. С носителем: рассказать день, попросить исправить связки.
4. Аудирование 30 мин/день — теперь ловите на слух -ып-цепочки, они везде.
