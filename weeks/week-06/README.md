# Неделя 6 — Хочу, нужно, можно

**Цель недели:** выражать желания, потребности и просить разрешения — 80% реальной коммуникации. Словарь — 800 слов.

## 1. керек — «нужно»

- Нужна вещь: **Мага + сущ. + керек**: *Мага суу керек* (мне нужна вода). *Сага эмне керек?* (что тебе нужно?)
- Нужно действие: **основа + -ыш/-иш/-уш/-үш + притяж. + керек**: *Бар**ышым** керек* (мне нужно идти), *Иште**шим** керек* (мне нужно работать), *Ал кел**иши** керек* (он должен прийти).
- Отрицание: *керек эмес* (не нужно).

## 2. -гым келет — «я хочу»

**Основа + -гы/-ги/-гу/-гү + притяж. + келет:**

*Бар**гым** келет* (хочу пойти), *Же**гим** келет* (хочу есть), *Укта**гым** келет* (хочу спать), *Көр**гүм** келет* (хочу увидеть).

Отрицание: *Баргым **келбейт*** (не хочу идти). Прошедшее: *Баргым **келди*** (захотелось пойти).

Хотеть вещь — глагол **каалоо**: *Эмне каалайсыз?* (что желаете?) — так спросят в кафе.

## 3. болот — «можно»

- Просьба разрешения: **-са/-се + болобу?**: *Кир**сем** болобу?* (можно войти?), *Сүрөт тарт**сам** болобу?* (можно сфотографировать?)
- Ответы: *Болот* (можно) / *Болбойт* (нельзя).
- **мүмкүн** — «возможно/может быть», **сөзсүз** — «обязательно».

## Задания

1. 10 предложений «сегодня мне нужно...» (*Бүгүн мен дүкөнгө барышым керек...*).
2. 10 желаний через -гым келет: реальные, про свою жизнь.
3. С носителем: сценарий «кафе» — заказать, попросить счёт, поблагодарить.
4. Аудирование 20–30 мин/день + 2–3 разговорных сессии.
