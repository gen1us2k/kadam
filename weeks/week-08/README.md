# Неделя 8 — Ревизия + причастие -ган

**Цель недели:** закрыть пробелы первых семи недель и добавить последний грамматический блок ядра. Словарь — 1100 слов.

## 1. Причастие -ган — «я делал/бывал» (перфект)

**Основа + -ган/-ген/-гон/-гөн** (после глухих -кан/-кен/-кон/-көн):

- Опыт: *Мен Ошко бар**ган**мын.* — Я бывал в Оше. *Сен кымыз ич**кен**сиңби?* — Ты пробовал кумыс?
- Отрицание опыта: *Мен Ошко барган **жокмун**.* — Я не бывал в Оше.
- Как определение: *кечээ кел**ген** киши* — человек, который вчера пришёл.

Разница с -ды: *бардым* — конкретное событие («вчера ходил»), *барганмын* — опыт вообще («доводилось бывать»).
