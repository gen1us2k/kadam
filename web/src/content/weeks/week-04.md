# Неделя 4 — Падежи 2, притяжательность, прошедшее время

**Цель недели:** говорить о своём/чужом и о том, что уже случилось. Словарь — 500 слов.

## 1. Родительный падеж (илик) + притяжательные аффиксы

Владелец получает **-нын/-дын/-тын**, вещь — притяжательный аффикс. Работают всегда парой:

*мен**ин** ата**м*** (мой отец), *Айгүл**дүн** китеб**и*** (книга Айгүль), *биз**дин** үй**үбүз*** (наш дом).

| | китеп (книга) |
|---|---|
| менин | китебим |
| сенин | китебиң |
| сиздин | китебиңиз |
| анын | китеби |
| биздин | китебибиз |
| силердин | китебиңер |
| алардын | китеби |

Обратите внимание: конечная глухая озвончается перед гласной суффикса (кит**еп** → кит**еб**им).

## 2. Винительный падеж (табыш)

**-ны/-ды/-ты** — только для определённого объекта:

*Мен китеп окудум* — я читал книгу (какую-то).
*Мен бул китеп**ти** окудум* — я прочитал эту (конкретную) книгу.

## 3. Прошедшее время (-ды)

| | баруу | келүү | иштөө |
|---|---|---|---|
| мен | бардым | келдим | иштедим |
| сен | бардың | келдиң | иштедиң |
| сиз | бардыңыз | келдиңиз | иштедиңиз |
| ал | барды | келди | иштеди |
| биз | бардык | келдик | иштедик |
| силер | бардыңар | келдиңер | иштедиңер |
| алар | барышты | келишти | иштешти |

После глухой согласной суффикс начинается с **т**: айт → айт**ты**м (я сказал).

Отрицание — та же вставка -ба-: *барбадым* (я не ходил).

## 4. Слова времени для прошедшего

**кечээ** (вчера), **бүгүн** (сегодня), **эртең менен** (утром), **кечинде** (вечером), **былтыр** (в прошлом году), **жакында** (недавно).

## «-ыптыр» — оказывается, сделал (прошедшее «со слов»)

У прошедшего есть **второй способ** кроме -ды. Он говорит: действие было, но я **не видел его сам** — узнал по следам, по итогу или с чужих слов. Русское «оказывается / говорят».

Основа + **-ыптыр / -иптир / -уптур / -үптүр** (после гласной -птыр…):

| Кыргызча | Русский |
|---|---|
| Ал келиптир. | Он, оказывается, пришёл (вижу по следам / говорят). |
| Жамгыр жааптыр. | Оказывается, прошёл дождь (земля мокрая). |
| Алар шаарга кетишиптир. | Они, оказывается, уехали в город. |
| Сен уктап калыптырсың. | Ты, оказывается, уснул. |

Это **пара к -ды по источнику знания**, а не по времени:

- *Ал келди.* — «пришёл» (я **видел**).
- *Ал келиптир.* — «оказывается, пришёл» (я **узнал**, не видел).

Чаще всего в 3-м лице (рассказ о других). **Ошибка русскоязычных:** ставить -ды на всё — тогда звучит, будто вы были свидетелем того, чего не видели. Про ненаблюдавшееся — -ыптыр (или нейтральное -ган).

## Словообразование: сотни слов бесплатно

Пять продуктивных суффиксов превращают известные слова в новые — это множитель словаря:

| Суффикс | Смысл | Примеры |
|---|---|---|
| **-луу/-лүү/-дуу/-туу** | «с чем-то, имеющий» | күчтүү (сильный), балалуу (с детьми), акчалуу (при деньгах), бактылуу (счастливый) |
| **-сыз/-сиз/-суз/-сүз** | «без» | акчасыз (без денег), үйсүз (бездомный), сөзсүз (безусловно — «без слов») |
| **-чы/-чи/-чу/-чү** | деятель, профессия | жумушчу (рабочий), балыкчы (рыбак), темирчи (кузнец), койчу (пастух) |
| **-лык/-дык/-тык** | абстракция, «-ость» | достук (дружба), балалык (детство), жакшылык (добро) |
| **-кана** | место, «-ная» | ашкана (столовая), китепкана (библиотека), дарыкана (аптека), мейманкана (гостиница) |

Пары для запоминания: **акчалуу ↔ акчасыз** (при деньгах ↔ без денег), **үйлүү ↔ үйсүз**. Все суффиксы подчиняются сингармонизму — гласную выбираете как обычно.

Теперь знакомые слова читаются насквозь: дары (лекарство) + кана = аптека; балык (рыба) + чы = рыбак; дос (друг) + тук = дружба.
