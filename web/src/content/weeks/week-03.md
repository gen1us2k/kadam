# Неделя 3 — Падежи 1: где, куда, откуда

**Цель недели:** свободно говорить о местоположении и направлении. Словарь — 350 слов.

## 1. Три «пространственных» падежа

| Падеж | Суффикс | Вопрос | Примеры |
|---|---|---|---|
| Жатыш (где) | -да/-де/-до/-дө, после глухих -та/... | кайда? | үйдө, Бишкекте, базарда, Ошто |
| Барыш (куда) | -га/-ге/-го/-гө, после глухих -ка/... | кайда? каякка? | үйгө, мектепке, Бишкекке, базарга |
| Чыгыш (откуда) | -дан/-ден/-дон/-дөн, после глухих -тан/... | кайдан? | үйдөн, Бишкектен, базардан |

Гласная — по сингармонизму, согласная — по последнему звуку корня (после глухой п/т/к/с/ш/ч суффикс начинается с т/к).

Особые формы местоимений в дательном: **мага** (мне), **сага** (тебе), **ага** (ему/ей).

## 2. Жатыш = ещё и «у кого»

*Мен**де** акча бар* — у меня есть деньги. *Сен**де** телефон барбы?* — у тебя есть телефон?

## 3. Послелоги места

После существительного: **жанында** (рядом с), **ичинде** (внутри), **үстүндө** (на), **астында** (под), **ортосунда** (между/посередине).

*Дүкөн үйдүн жанында* — магазин рядом с домом.

## 4. Послелог менен («с»)

*Досум менен барам* — пойду с другом. *Автобус менен* — на автобусе.

## Мини-диалог недели

— Кайда барасың? — Куда идёшь?
— Базарга барам. Сенчи? — На базар. А ты?
— Мен үйгө бара жатам. — Я иду домой.
— Базар алыспы? — Базар далеко?
— Жок, жакын. Аялдаманын жанында. — Нет, близко. Рядом с остановкой.

## Задания

1. Просклонять по трём падежам: үй, мектеп, базар, көл, шаар, Бишкек, Ош, жумуш.
2. Описать свой день маршрутом: *Эртең менен жумушка барам. Кечинде үйгө келем.* — 8–10 предложений.
3. В городе (или по карте) проговаривать: где я, куда иду, откуда пришёл.
4. Аудирование 20 мин/день.
