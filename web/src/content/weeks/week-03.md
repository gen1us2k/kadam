# Неделя 3 — Падежи 1: где, куда, откуда

**Цель недели:** свободно говорить о местоположении и направлении. Словарь — 350 слов.

## 1. Три «пространственных» падежа

| Падеж | Суффикс | Вопрос | Примеры |
|---|---|---|---|
| Жатыш (где) | -да/-де/-до/-дө, после глухих -та/... | кайда? | үйдө, Бишкекте, базарда, Ошто |
| Барыш (куда) | -га/-ге/-го/-гө, после глухих -ка/... | кайда? каякка? | үйгө, мектепке, Бишкекке, базарга |
| Чыгыш (откуда) | -дан/-ден/-дон/-дөн, после глухих -тан/... | кайдан? | үйдөн, Бишкектен, базардан |

Гласная — по сингармонизму, согласная — по последнему звуку корня (после глухой п/т/к/с/ш/ч суффикс начинается с т/к).

Особые формы местоимений в дательном: **мага** (мне), **сага** (тебе), **ага** (ему/ей).

**Примеры:**

- *Асел базарда.* — Асель на базаре.
- *Мен мектепке барам.* — Я иду в школу.
- *Автобус аялдамадан келет.* — Автобус приходит с остановки.
- *Биз көлгө барабыз.* — Мы едем на озеро.

## 2. Жатыш = ещё и «у кого»

*Мен**де** акча бар* — у меня есть деньги. *Сен**де** телефон барбы?* — у тебя есть телефон?

**Примеры:**

- *Менде эки китеп бар.* — У меня есть две книги.
- *Сенде калем барбы?* — У тебя есть ручка?
- *Анда машина жок.* — У него нет машины.
- *Бизде нан бар.* — У нас есть хлеб.

## 3. Послелоги места

После существительного: **жанында** (рядом с), **ичинде** (внутри), **үстүндө** (на), **астында** (под), **ортосунда** (между/посередине).

*Дүкөн үйдүн жанында* — магазин рядом с домом.

**Примеры:**

- *Китеп үстөлдүн үстүндө.* — Книга на столе.
- *Дүкөн мектептин жанында.* — Магазин рядом со школой.
- *Телефон баштыктын ичинде.* — Телефон в сумке.
- *Ит үйдүн астында.* — Собака под домом.

## 4. Послелог менен («с»)

*Досум менен барам* — пойду с другом. *Автобус менен* — на автобусе.

**Примеры:**

- *Мен апам менен базарга барам.* — Я иду на базар с мамой.
- *Биз автобус менен барабыз.* — Мы едем на автобусе.
- *Чай сүт менен даамдуу.* — Чай с молоком вкусный.
- *Ал досу менен иштейт.* — Он работает с другом.

## Мини-диалог недели

— Кайда барасың? — Куда идёшь?
— Базарга барам. Сенчи? — На базар. А ты?
— Мен үйгө бара жатам. — Я иду домой.
— Базар алыспы? — Базар далеко?
— Жок, жакын. Аялдаманын жанында. — Нет, близко. Рядом с остановкой.

## Ещё послелоги: о чём, через, каждый, после

Кроме менен есть с десяток послелогов-рабочих лошадок. Главное — запомнить, **какой падеж каждый требует**:

**С основным падежом (слово не меняется):**

| Кыргызча | Русский |
|---|---|
| Сен жөнүндө / тууралуу ойлоном. | Думаю о тебе. |
| телефон аркылуу | по телефону / через телефон |
| район боюнча | по району / согласно |
| күн сайын, жыл сайын | каждый день, каждый год |
| Асан өңдүү / сыяктуу жигит | парень, похожий на Асана |

**С дательным (-га):** *стадионго карай* — в сторону стадиона.

**С исходным (-дан):** *иштен кийин* — после работы; *Аселден мурун* — раньше Асели.

Ошибка русскоязычных — калькировать русское управление: «думаю **о тебе**» тянет поставить падеж, но жөнүндө берёт слово как есть: *сен жөнүндө* (не *сенден/сенге жөнүндө*).

**Примеры:**

- *Ал иш жөнүндө айтат.* — Он говорит о работе.
- *Мен күн сайын мектепке барам.* — Я каждый день хожу в школу.
- *Иштен кийин үйгө барам.* — После работы иду домой.
- *Мен телефон аркылуу сүйлөйм.* — Я говорю по телефону.
