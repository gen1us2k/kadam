# Неделя 7 — Связная речь: деепричастие -ып и союзы

**Цель недели:** перейти от отдельных предложений к связному рассказу. Словарь — 950 слов.

## 1. Деепричастие -ып — главный связыватель действий

**Основа + -ып/-ип/-уп/-үп** (после гласной — просто **-п**) соединяет последовательные действия. Кыргызская речь строится цепочками:

*Базарга бар**ып**, нан ал**ып**, үйгө келдим.* — Сходил на базар, купил хлеб и пришёл домой. (Время показывает только последний глагол.)

*Эртең менен тур**уп**, жуун**уп**, чай ич**ип**, жумушка бардым.* — Утром встал, умылся, попил чаю и пошёл на работу.

## 2. Составные глаголы с -ып — учить как единые слова

| Кыргызча | Орусча |
|---|---|
| сатып алуу | покупать («взяв продажей») |
| алып келүү | приносить |
| алып баруу | относить/отвозить |
| алып кетүү | забирать с собой |
| кирип чыгуу | заглянуть/зайти ненадолго |

## 3. Союзы и связки

| Кыргызча | Орусча |
|---|---|
| жана | и |
| же | или |
| бирок | но |
| анан | потом, затем |
| анткени / себеби | потому что |
| ошондуктан | поэтому |
| эгер ... -са | если ... |
| деген | который называется / под названием |

*Мен келбедим, **анткени** ооруп жаттым.* — Я не пришёл, потому что болел.
*«Эгер убактым бол**со**, барам.»* — Если будет время, пойду. (условная форма -са/-се)

## 4. Хочешь звучать естественно — жат/отур/тур/жүр

Вспомогательные глаголы уточняют характер действия; на старте достаточно узнавать их на слух: *окуп отурат* (сидит читает), *иштеп жүрөт* (работает [в этот период жизни]).

## Аспектуальные «-ып + вспомогательный»

Кыргыз редко говорит просто «сделал» — к деепричастию на **-ып** он добавляет вспомогательный глагол, и тот придаёт оттенок. Это то, что делает речь «живой». Учить парами:

| Конструкция | Оттенок | Пример |
|---|---|---|
| -ып **бер** | для кого-то | окуп бер — почитай мне |
| -ып **ал** | для себя | сатып ал — купи (себе); окуп ал — прочитай (для себя) |
| -ып **кой** | сделать/отложить «пусть будет» | жазып кой — запиши, отметь |
| -ып **кал** | внезапно/нечаянно; остаться | уктап калды — уснул; калып калды — остался |
| -ып **жибер** | резко / отправить | айтып жибер — выпали; жөнөтүп жибер — отправь |

Сравните: *сатам* (продаю) → *сатып алам* (покупаю, «беру себе»); *уктадым* (спал) → *уктап калдым* (заснул, нечаянно).

**Совет:** специально лови эти пары на слух у носителей — они везде. Потом вставляй в просьбы: *окуп берчи* (почитай-ка мне).

## Сложное предложение без союзов: -ганда, -ганча, -майынча, -ганы

Кыргызский связывает части предложения не союзами, а деепричастиями на базе причастия **-ган**. Четыре главных:

| Форма | Значение | Пример |
|---|---|---|
| **-ганда** | «когда» | Ал келгенде айтам. — Скажу, когда он придёт. |
| **-ганча** | «пока не / до того как» | Сен келгенче күтөм. — Подожду, пока ты не придёшь. |
| **-ганча** (2) | «чем / вместо того чтобы» | Отуруп турганча, иште. — Чем сидеть, работай. |
| **-майынча** | «пока не …» (уже с отрицанием) | Бүтмөйүнчө барбайм. — Не пойду, пока не закончу. |
| **-ганы** | «чтобы» (с глаголами движения) | Нан алганы бардым. — Пошёл, чтобы купить хлеб. |

Обратите внимание: у **-ганча** два значения — «до того как» и «чем» (сравнение), различаются по контексту. У **-майынча** отрицание уже внутри, поэтому главный глагол тоже обычно отрицательный (барбайм).

**Русская привычка** рубить на «и потом… и потом…» или связывать союзами «чтобы/пока/когда» должна уйти: кыргыз вешает эти смыслы прямо на глагол.

1. Переписать 10 пар коротких предложений в одно с -ып: «Я встал. Я умылся» → *Туруп, жуундум.*

3. С носителем: рассказать день, попросить исправить связки.
4. Аудирование 30 мин/день — теперь ловите на слух -ып-цепочки, они везде.
