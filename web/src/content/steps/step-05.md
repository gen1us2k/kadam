# Шаг 5 — Вопросы, числа, деньги, покупки

**Цель:** уверенно справляться с базаром, магазином, такси. С этой недели — **разговорная практика с носителем 2–3 раза в неделю, обязательно.** Словарь — 650 слов.

## 1. Все вопросительные слова

| Кыргызча | Орусча |
|---|---|
| ким? | кто? |
| эмне? | что? |
| кайда? / кайдан? | где, куда? / откуда? |
| качан? | когда? |
| канча? / канчада? | сколько? / во сколько? |
| кандай? | какой? как? |
| кайсы? | который? |
| эмнеге? / эмне үчүн? | почему? / зачем? |
| кантип? | как? (каким образом) |

С вопросительным словом частица -бы не нужна: *Канча турат?* (сколько стоит?).

**Примеры:**

- *Ким келди?* — Кто пришёл?
- *Бул эмне?* — Что это?
- *Сен кайда барасың?* — Куда ты идёшь?
- *Автобус качан келет?* — Когда придёт автобус?

## 2. Числа полностью

1–10: бир, эки, үч, төрт, беш, алты, жети, сегиз, тогуз, он.
Десятки: жыйырма (20), отуз (30), кырк (40), элүү (50), алтымыш (60), жетимиш (70), сексен (80), токсон (90).
**жүз** (100), **миң** (1000). Составные — просто подряд: *беш жүз элүү сом* (550 сомов).

## 3. Время на часах

*Саат канча?* — который час? *Саат беш* — пять часов. *Саат канчада?* — во сколько? *Саат бешт**е*** — в пять (местный падеж).

**Примеры:**

- *Азыр саат жети.* — Сейчас семь часов.
- *Саат канчада келесиң?* — Во сколько придёшь?
- *Мен саат сегизде келем.* — Я приду в восемь.
- *Автобус саат алтыда келет.* — Автобус придёт в шесть.

## 4. Сценарий «покупка» — довести до автоматизма

Раздел «Базар, магазин, кафе» из [разговорника](../../phrases.md):
*Бул канча турат? Кымбат экен. Арзаныраак болобу? Мага бир кило алма бериңизчи. Рахмат!*

Сравнение: **-ыраак/-ирээк** = «по-...е»: арзан**ыраак** (подешевле), чоң**ураак** (побольше), кичине**рээк** (поменьше).

## 5. Будущее — повторение

Настоящее-будущее время уже выражает будущее: *Эртең мен базарга барам, эт алам.* Добавьте слова: **эртең** (завтра), **бүрсүгүнү** (послезавтра), **кийинки жумада** (на следующей неделе).

## Сравнение: -ыраак, эң, -дан, -дай

Пригодится сразу на базаре (арзаныраак!) и в любом разговоре.

- **«-ее» (сравнительная):** основа + **-ыраак/-ирээк/-ураак/-үрөөк** (после гласной -раак): арзан → **арзаныраак** (подешевле), чоң → **чоңураак** (побольше), жакшы → **жакшыраак** (лучше).
- **«чем» (исходный падеж -дан):** *менден чоң* — больше/старше меня; *темирден оор* — тяжелее железа.
- **«самый» (эң):** *эң жакшы* (самый лучший), *эң кооз* (самый красивый).
- **«как / подобно» (-дай/-дей):** *таштай катуу* (твёрдый как камень), *кардай ак* (белый как снег).

| Кыргызча | Русский |
|---|---|
| Бул арзаныраак болобу? | Можно подешевле? |
| Ал менден чоң. | Он старше меня. |
| Эң жакшы досум. | Мой самый лучший друг. |
| Балдай таттуу. | Сладкий как мёд. |

Порядок «чем»: то, с чем сравниваем, идёт в исходном падеже **перед** прилагательным: *X-тан [прилаг.]* = «[прилаг.]-ее, чем X».

**Примеры:**

- *Мына бул алма чоңураак.* — Вот это яблоко побольше.
- *Бишкек Оштон чоң.* — Бишкек больше Оша.
- *Ал эң бийик тоо.* — Это самая высокая гора.
- *Кыз айдай сулуу.* — Девушка красива как луна.

## Производные числительные: первый, вдвоём, по одному

- **Порядковые «-ый» — -(ы)нчы/-(и)нчи:** биринчи (первый), экинчи (второй), онунчу (десятый). *Мен экинчи курста окуйм* — я учусь на втором курсе.
- **Собирательные «вдвоём/втроём» — -өө/-оо** (только 1–7): экөө (двое), үчөө (трое), алтоо (шестеро). С лицом: **экөөбүз** (мы вдвоём). *Экөө шахмат ойношту* — двое играли в шахматы.
- **«По … штук» — исходный -дан:** бирден (по одному), экиден (по два), *отуздан отурдук* (садились по тридцать).
- **Доли:** жарым (половина: *эки жарым* — два с половиной), чейрек (четверть), дроби через -дан: *үчтөн эки* (две трети).

**Примеры:**

- *Мен биринчи келдим.* — Я пришёл первым.
- *Экөөбүз базарга бардык.* — Мы вдвоём пошли на базар.
- *Бизге бирден алма бериңиз.* — Дайте нам по одному яблоку.
- *Мага жарым кило эт бериңиз.* — Дайте мне полкило мяса.

## Местоимения: кто-то, никто, все, сам

Система из четырёх рядов — закрывает почти все «кто/что»-слова:

| Ряд | Кыргызча | Русский |
|---|---|---|
| неопределённые | бирөө, кимдир бирөө | кто-то, некто |
| отрицательные | эч ким, эч нерсе, эч качан, эч кайда | никто, ничто, никогда, никуда |
| определительные | баары, ар бир, ар ким | все, каждый, всякий |
| возвратное | өзүм, өзүң, өзү | я сам, ты сам, он сам |

Правила:

- **эч** требует отрицательного глагола (двойное отрицание — норма): *Залда эч ким **жок**. Эч кайда барган **жокпуз*** (никуда не ходили).
- **өз** склоняется с притяжательным: *Бул ишти өзүң аткарышың керек* — эту работу ты должен сделать **сам**.
- *Кимдир бирөө үйгө кирди* — кто-то вошёл в дом. *Студенттердин баары келди* — пришли все студенты.

**Примеры:**

- *Мен эч нерсе билбейм.* — Я ничего не знаю.
- *Бирөө сени күтүп жатат.* — Кто-то тебя ждёт.
- *Баары үйгө кетти.* — Все ушли домой.
- *Мен өзүм жасайм.* — Я сам сделаю.
