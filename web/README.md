# Kyrgyz 80/20 — веб-приложение

Приложение-путь изучения кыргызского. Построено на [Astro](https://astro.build) + React-остров.

## Принцип

Уроки живут внутри приложения: **`src/content/weeks/week-NN.md`** — единственный источник
контента шагов. Разговорник и словарь читаются из корня репозитория (`../phrases.md`,
`../anki/kyrgyz-frequency.csv`) без дублирования. Уроки разбиваются на темы и встраиваются
внутрь шагов пути; недельно-дневной каркас («неделя N», «дни…», цели недели, мета-секции)
отбрасывается при сборке.

## Команды

```bash
npm install
npm run dev       # http://localhost:4321
npm run build     # статическая сборка в ./dist
npm run preview   # предпросмотр ./dist
```

## Структура

```
src/
  content/weeks/           # week-NN.md — источник уроков (контент шагов пути)
  content.config.ts        # glob-загрузчики: weeks (локально) + phrases (из корня)
  layouts/Base.astro       # оболочка: шапка, навигация, тема
  pages/
    index.astro            # ГЛАВНАЯ = путь изучения (journey) + дневной баннер
    study.astro            # дневная сессия: смешанное FSRS-повторение + дриллы + статистика
    reader.astro           # чтение с кликом-переводом
    phrases.astro          # разговорник (../phrases.md)
    vocab.astro            # браузер словаря (CEFR-фильтр, примеры, Forvo)
  components/
    Journey.tsx            # маршрут: раскрываемые шаги с инлайн-контентом, prev/next, прогресс
    StudySession.tsx       # карточки с лестницей режимов: выбор KG→RU → выбор RU→KG → ввод → cloze
    Drills.tsx             # грамм-дриллы на движке морфологии (мн.ч. + 3 падежа)
    StatsPanel.tsx         # прогресс: зрелые, точность, слабые слова, стрик
    DailyBanner.tsx        # дневная цель + стрик на главной
    Reader.tsx             # разбор текста, словарный клик-перевод (отрезание суффиксов)
    VocabBrowser.astro     # поиск/фильтр словаря
  lib/
    lessons.ts             # разбивка недели на темы + очистка заголовков/ссылок (pure)
    journey.ts             # сборка шагов: тема → слова → повторение → корпус (pure)
    srs.ts                 # состояние карточек, очередь (interleaved), статистика, миграция v1→v2
    fsrs.ts                # планировщик FSRS-6 (официальные формулы и веса)
    morphology.ts          # сингармонизм: мн.ч., жатыш/барыш/чыгыш + генератор дриллов
    daily.ts               # дневная цель и стрик
    vocab.ts               # парсер/мерж CSV-колод
    remark-rewrite-links.mjs
  styles/global.css
```

## Модель пути

`lessons.ts` режет каждую неделю по `##`-темам, выкидывает мета-секции (Лексика/Задания/Чеклист),
чистит заголовки от «недели/дни». `index.astro` рендерит markdown тем в HTML через `marked` и
передаёт шаги в `Journey`. Грамматический шаг раскрывается с контентом урока; шаги «слова» и
«повторение» запускают `StudySession` (фильтр по неделе / глобальная очередь). Прогресс — localStorage.

## Что сознательно НЕ делали (YAGNI)

Ни аккаунтов, ни бэкенда, ни синхронизации: состояние (FSRS-карточки, стрик, прогресс пути)
живёт в localStorage.

## Озвучка (встроенный TTS)

Произношение синтезируется **в браузере**: Meta MMS (facebook/mms-tts-kir) в ONNX
(конверсия willwade/mms-tts-multilingual-models-onnx) через onnxruntime-web (`lib/tts.ts`).
Модель (~113 МБ) скачивается с CDN HuggingFace **один раз** при первом клике 🔊 и кэшируется
Cache API; дальше синтез офлайн. Кнопки — в карточках, дриллах, читалке и словаре.
Google TTS не поддерживает кыргызский (проверено, 400), Forvo не встраивается без платного API,
int8-квантование модели отвергнуто (ConvInteger не поддержан ORT) — отсюда выбор.
