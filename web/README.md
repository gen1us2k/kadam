# Kyrgyz 80/20 — веб-приложение

Приложение-путь изучения кыргызского. Построено на [Astro](https://astro.build) + React-остров.

## Принцип

Единственный источник правды — markdown и CSV в **корне репозитория** (`../weeks`, `../phrases.md`,
`../anki/kyrgyz-frequency.csv`). Приложение читает их напрямую и ничего не дублирует. Уроки из
недельного markdown разбиваются на темы и встраиваются внутрь шагов пути; недельно-дневной каркас
(«неделя N», «дни…», цели недели, мета-секции) отбрасывается при сборке.

## Команды

```bash
npm install
npm run dev       # http://localhost:4321
npm run build     # статическая сборка в ./dist
npm run preview   # предпросмотр ./dist
```

## Структура

```
src/
  content.config.ts        # glob-загрузчик недель (источник контента шагов) + phrases
  layouts/Base.astro       # оболочка: шапка, навигация, тема
  pages/
    index.astro            # ГЛАВНАЯ = путь изучения (journey). Рендерит темы недель через marked
    study.astro            # глобальное интервальное повторение
    phrases.astro          # разговорник (../phrases.md)
    vocab.astro            # браузер словаря
  components/
    Journey.tsx            # маршрут: раскрываемые шаги с инлайн-контентом, prev/next, прогресс
    StudySession.tsx       # SRS-квиз (переиспользуется в шагах vocab/review и на /study)
    VocabBrowser.astro     # поиск/фильтр словаря
  lib/
    lessons.ts             # разбивка недели на темы + очистка заголовков/ссылок (pure)
    journey.ts             # сборка шагов: тема → слова → повторение (pure)
    srs.ts                 # Leitner-движок интервального повторения (pure + localStorage)
    vocab.ts               # парсер CSV
    remark-rewrite-links.mjs
  styles/global.css
```

## Модель пути

`lessons.ts` режет каждую неделю по `##`-темам, выкидывает мета-секции (Лексика/Задания/Чеклист),
чистит заголовки от «недели/дни». `index.astro` рендерит markdown тем в HTML через `marked` и
передаёт шаги в `Journey`. Грамматический шаг раскрывается с контентом урока; шаги «слова» и
«повторение» запускают `StudySession` (фильтр по неделе / глобальная очередь). Прогресс — localStorage.

## Что сознательно НЕ делали (YAGNI)

Движок интервального повторения — Leitner, не SM-2/FSRS (изолирован в `srs.ts`, заменяется).
Ни аккаунтов, ни бэкенда, ни синхронизации: состояние живёт в localStorage.
