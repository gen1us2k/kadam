# Learn Kyrgyz the hard way

Кыргызский с нуля за 10–12 недель для русскоговорящего. Принцип 80/20: учим только то, что даёт максимум понимания и речи на единицу времени. Цель — уверенный A2 за 3 месяца при ~1.5 ч/день.

## Почему у русскоговорящего фора

- **Кириллица.** Кыргызский алфавит = русский + 3 буквы: **ң, ө, ү**. Читать умеете с первого дня.
- **Заимствования.** Бытовая городская лексика во многом русская (машина, автобус, документ). Это сотни «бесплатных» слов.
- **Грамматика проще русской в главном:** нет родов, нет видовых пар глаголов, почти нет исключений. Всё строится суффиксами по регулярным правилам.

## 20% усилий, дающие 80% результата

1. **Сингармонизм (гармония гласных)** — главный ключ. Одно правило определяет форму *всех* суффиксов. Выучите его первым — дальше грамматика станет предсказуемой. → [Неделя 1](weeks/week-01/README.md)
2. **6 падежей** — суффиксы вместо русских окончаний, логика похожая. → [Недели 3–4](weeks/week-03/README.md)
3. **3 времени в базовой форме:** настоящее (-ып жатат), прошедшее (-ды), настоящее-будущее (-ат). → [Недели 2, 4, 5](weeks/week-02/README.md)
4. **Личные и притяжательные аффиксы:** мен келе**м**, сен келе**сиң**; китеб**им** «моя книга».
5. **Порядок слов SOV** — глагол в конце: «Мен нан алдым» (я хлеб купил). Главный ментальный сдвиг.
6. **~1200–1500 частотных слов** — покрывают ~80% бытовой речи. → [anki/](anki/)
7. **Отрицание и вопрос:** -ба/-бе, эмес, жок; вопросительная частица -бы/-би.

## Ежедневная рутина (~1–1.5 часа)

- 20 мин Anki (новые слова + повторение) — не пропускать, это несущая конструкция.
- 20–30 мин грамматика/упражнения из недельного каталога.
- 20 мин аудирование (Азаттык, Ala-Too 24, музыка).
- Разговорная практика с 5-й недели 2–3 раза в неделю. Если вы в Кыргызстане — базар, такси, магазин: заставляйте себя говорить.

## Ресурсы

- **Peace Corps Kyrgyz Language Manual** — бесплатный PDF, лучший структурированный курс для начинающих.
- **Anki** — колода из [anki/kyrgyz-frequency.csv](anki/kyrgyz-frequency.csv), пополняйте своими словами.
- **Азаттык** (радио/сайт/YouTube) — новости на кыргызском, чёткая дикция.
- **italki / Preply** — репетиторы-носители, недорого.
- Google Translate поддерживает кыргызский — годится для проверки, не для обучения.

## Чего НЕ делать (анти-80/20)

- Не учить редкие глагольные формы и литературные времена — их около десятка, в быту нужны 3.
- Не добиваться идеального произношения ө/ү в первый месяц — поймут и так.
- Не читать классику (Айтматова в оригинале) до 3-го месяца.
- Не коллекционировать учебники — один курс + Anki + носитель.

## Реалистичное ожидание

За 3 месяца при ~1.5 ч/день: уверенный A2 — бытовые разговоры, поездки, базар, простые тексты. Свободная речь — нет, но фундамент будет полный.
