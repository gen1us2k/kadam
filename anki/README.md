# Anki-колода: частотный словарь

Файл [kyrgyz-frequency.csv](kyrgyz-frequency.csv) — ~450 частотных слов и фраз с русским переводом, размеченных тегами по неделям курса и темам.

## Формат

3 колонки, разделитель — запятая:

```
кыргызча,орусча,теги
```

Первые строки файла (`#separator`, `#html`, `#tags column`) — служебные директивы Anki, они настроят импорт автоматически.

## Импорт

1. Anki → Файл → Импортировать → выбрать `kyrgyz-frequency.csv`.
2. Тип заметки: **Basic** (или Basic + reversed card, если хотите карточки в обе стороны — рекомендую).
3. Проверить соответствие: поле 1 → Front, поле 2 → Back, поле 3 → Tags.
4. Импортировать.

## Как заниматься

- **20 новых карточек в день** — темп курса (~140 слов/неделю с учётом фраз).
- Учить по тегам недели: Пресеты → Custom Study → по тегу `week01`, `week02`, ...
- Повторения не копить: пропущенный день Anki — два дня расплаты.
- Проговаривайте карточку вслух — колода должна работать на речь, не на узнавание.

## Пополнение

Добавляйте свои слова из аудирования и чтения в этот же файл (или прямо в Anki) с тегом текущей недели. К концу курса колода должна вырасти с ~450 до 1500 за счёт ваших находок — это нормально и запланировано: базовая колода даёт каркас, живой словарь приходит из практики.
